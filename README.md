# 📅 AI计划表（ai-planer）

> 把你在 DeepSeek 里规划的计划一键导入，AI 自动解析成可打卡、可提醒的任务。Windows 桌面应用，纯本地运行，支持长达四年的长期计划。

## ✨ 功能亮点

### 🤖 AI 解析聊天记录

- 粘贴聊天记录，或选择导出的 `.txt / .md / .json` 文件
- 调用 DeepSeek API 自动提取所有任务
- 自动识别：一次性任务、重复任务（每天/每周/每月/每年）、周计划（第 N 周 / 第 N~M 周）、持续任务、打卡次数（例如「10月22号前刷完1000题，每天100题」→ 自动算出**打卡 10 次**）

### 🗂 任务类型

| 类型   | 说明                                                 |
| ---- | -------------------------------------------------- |
| 一次性  | 到点提醒一次，勾选即完成                                       |
| 重复   | 按频率反复提醒，可设间隔、星期几、结束时间；**打勾只算「今天完成」，明天自动恢复**        |
| 持续任务 | 有明确时间段（如「10月22号前刷完1000题」），期间每天提醒，用「已完成」按钮提前结束（可撤销） |
| 打卡次数 | 独立机制：卡片显示「×N」剩余次数，**打卡满 N 次自动完成**，不必每天打            |

### 🖥 今日视图（极简模式）

- 2×2 象限布局，每个区域可选：今日 / 全部 / 未来 N 天 / 已过期
- 管理模式：拖分隔线调整大小、长按拖动交换区域、添加/删除区域
- 未完成的任务排最上面；打卡后变灰划线（误触再点一下即恢复）
- 在「未来 / 全部」区域打勾 = 自动打卡**下一个未打卡日期**

### 🔔 可靠提醒

- 常驻系统托盘 + Windows 原生通知，支持开机自启
- 关机期间错过的提醒，下次启动**自动补发**（默认补最近 7 天）
- 可设提前 N 分钟提醒（默认 30 分钟）；全天任务上午 9:00 提醒

### 🔒 隐私安全

- 数据全部保存在本机 `%APPDATA%\ai-planer\data.json`，原子写入防损坏
- 不上传任何计划数据；API Key 仅存于本地配置文件

## 📦 安装

从 [Releases](../../releases) 页面下载 `AI计划表 Setup 1.0.0.exe` 安装（Windows x64）。

> 首次运行请在「设置」页填写 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 获取）。

## 🚀 开发运行

```bash
npm install   # 安装依赖（首次自动下载 Electron）
npm start     # 启动应用
```

## 🔨 打包

```bash
npm run icon   # 生成图标（仓库已含，通常无需重复）
npm run dist   # 打包 NSIS 安装包，产物在 release/
```

## 📖 使用步骤

1. 「设置」页填写 DeepSeek API Key
2. 「导入」页粘贴聊天记录或选择导出文件，点击「AI 解析」
3. 勾选 / 修改解析结果，导入任务
4. 「今日」页查看今天的任务并打卡；「编辑计划」页批量管理全部任务
5. 关闭窗口后程序缩到系统托盘，到点弹出通知

## 🧱 技术栈

- Electron 33（托盘、系统通知、开机自启）
- 原生 JS + CSS（无前端框架）
- DeepSeek API（OpenAI 兼容格式）做计划解析
- JSON 文件原子持久化（无数据库依赖）

## 📁 目录结构

```
electron/   主进程（main.js 窗口/托盘/通知 · scheduler.js 调度 · store.js 存储 · ai.js AI解析 · preload.js）
renderer/   界面（index.html · styles.css · app.js）
scripts/    图标生成脚本
assets/     应用图标
```
